# Oyips-Analysis
Oyip's Analysis

«We let the data talk.»

Oyip's Analysis is a collection of practical data analysis and data science projects focused on understanding real-world questions through data, statistics, mathematics, machine learning, and scientific reasoning.

The goal is not just to build models, but to understand why the patterns exist, what the data can actually tell us, and where the limitations are.

What You'll Find Here

- Exploratory Data Analysis
- Statistical analysis
- Data visualization
- Mathematical modelling
- Machine learning
- Real-world datasets and questions
- Scientific and quantitative reasoning

Projects

Week 01 — Vehicle Weight & Fuel Efficiency

Question: Does vehicle weight affect fuel efficiency?

Using the Auto MPG dataset, this analysis investigates the relationship between vehicle weight and fuel efficiency and explores how other variables such as horsepower and model year influence the relationship.

Key ideas:

- Correlation
- Linear regression
- Multiple regression
- Model evaluation
- Residual analysis
- Interpreting relationships between variables
- Connecting statistical results with physical intuition

More projects will be added weekly.

Approach

Each analysis follows a simple principle:

Ask → Explore → Measure → Model → Interpret

The objective is to let the evidence guide the conclusion rather than forcing a conclusion onto the data.
